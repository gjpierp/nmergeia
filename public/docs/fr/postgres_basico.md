# Fundamentos

## 1. Introducción a Bases de Datos Relacionales
PostgreSQL es un sistema de gestión de bases de datos relacionales objeto-relacional (ORDBMS) muy potente y de código abierto.

## 2. Instalación y Configuración Básica
- Instalación en Windows/Linux/Mac.
- Configuración inicial de `pg_hba.conf` y `postgresql.conf`.
- Comandos básicos de psql (`\l`, `\dt`, `\du`).

## 3. Comandos CRUD Básicos
- **CREATE**: Creación de tablas y bases de datos.
- **READ**: Consultas `SELECT`, filtrado básico con `WHERE`.
- **UPDATE**: Modificación de registros existentes.
- **DELETE**: Eliminación de datos.

## 4. Tipos de Datos Principales
- Tipos numéricos (`INTEGER`, `NUMERIC`).
- Tipos de caracteres (`VARCHAR`, `TEXT`).
- Tipos de fecha/hora (`TIMESTAMP`, `DATE`).
- Tipos booleanos (`BOOLEAN`).
