# Nivel Avanzado - Introducción a PL/SQL

Oracle no solo almacena datos; permite procesarlos *in-situ* mediante **PL/SQL** (Procedural Language/Structured Query Language). Ejecutar la lógica cerca de los datos reduce masivamente la latencia de red entre el backend y la base de datos.

## 1. Estructura de un Bloque PL/SQL

Un bloque PL/SQL tiene tres partes: Declaración, Ejecución y Excepción (manejo de errores).

```sql
DECLARE
    v_nombre VARCHAR2(100);
    v_precio NUMBER;
BEGIN
    SELECT nombre, precio INTO v_nombre, v_precio 
    FROM productos 
    WHERE producto_id = 1;
    
    DBMS_OUTPUT.PUT_LINE('Producto: ' || v_nombre || ' vale ' || v_precio);
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('El producto no existe.');
END;
/
```
*(Nota: Para ver la salida de `DBMS_OUTPUT` en SQL*Plus o SQL Developer, ejecuta primero `SET SERVEROUTPUT ON;`)*

## 2. Procedimientos Almacenados y Funciones

Para reutilizar bloques PL/SQL desde tu backend (Node.js, Java, .NET), se encapsulan en Procedimientos o Funciones.

### Crear un Procedimiento

Los procedimientos realizan acciones y pueden tener parámetros de entrada (`IN`), salida (`OUT`) o ambos (`IN OUT`).

```sql
CREATE OR REPLACE PROCEDURE actualizar_precio (
    p_id IN NUMBER,
    p_porcentaje_aumento IN NUMBER
) AS
BEGIN
    UPDATE productos
    SET precio = precio + (precio * (p_porcentaje_aumento / 100))
    WHERE producto_id = p_id;
    
    COMMIT;
EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
        RAISE_APPLICATION_ERROR(-20001, 'Error al actualizar el precio.');
END;
/
```

### Crear una Función

Las funciones siempre deben retornar un valor (`RETURN`).

```sql
CREATE OR REPLACE FUNCTION obtener_inventario_total RETURN NUMBER AS
    v_total NUMBER;
BEGIN
    SELECT SUM(precio) INTO v_total FROM productos;
    RETURN NVL(v_total, 0); -- NVL maneja valores nulos
END;
/
```

## 3. Triggers (Disparadores)

Los Triggers ejecutan código automáticamente antes (`BEFORE`) o después (`AFTER`) de un evento DML (INSERT, UPDATE, DELETE). Son vitales para mantener logs de auditoría.

```sql
-- Tabla para auditoría
CREATE TABLE auditoria_productos (
    log_id NUMBER GENERATED BY DEFAULT AS IDENTITY,
    producto_id NUMBER,
    accion VARCHAR2(50),
    fecha DATE DEFAULT SYSDATE
);

-- Trigger que registra cambios de precio
CREATE OR REPLACE TRIGGER trg_audit_productos
AFTER UPDATE OF precio ON productos
FOR EACH ROW
BEGIN
    INSERT INTO auditoria_productos (producto_id, accion)
    VALUES (:OLD.producto_id, 'Cambio de precio de ' || :OLD.precio || ' a ' || :NEW.precio);
END;
/
```
