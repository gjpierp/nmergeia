# 先进的软件架构

系统的结构设计决定了其可扩展性、可维护性和弹性。

## 六边形架构（端口和适配器）
将域的核心与外部依赖项（数据库、UI、API）分开。该域不了解基础设施。
- **端口：** 由域定义的接口。
- **适配器：** 与端口连接的技术实现。

## 面向事件的架构 (EDA)
组件通过异步事件的发出和消耗进行通信（编排与编排）。
- 高负载和弱耦合系统的理想选择。

``美人鱼
图解TD
  A[UI 适配器] -->|命令| B[核心领域]
  C[数据库适配器] -.->|实现| D[端口存储库]
  B-->D
  B -->|发布| E[活动巴士]
````
