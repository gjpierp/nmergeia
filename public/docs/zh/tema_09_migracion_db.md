# DB之间的迁移和互操作

退出旧数据库或本地数据库的策略（例如从 Oracle 到 Postgres）。

## 迁移工具
使用 *AWS SCT（架构转换工具）* 和 *DMS（数据迁移服务）* 进行 CDC（变更数据捕获）复制。

## 扼杀者无花果策略
将表迁移到表。应用程序会进行双重写入，直到确认完整性为止。

````美人鱼
图解TD
  A[单体应用程序] --> B[Oracle DB]
  A --> C[新微服务]
  C --> D[PostgreSQL]
  B-。 CDC 同步.-> D
````

> 白皮书的其余部分保留其原始语言，以保留代码和图表的语法。
