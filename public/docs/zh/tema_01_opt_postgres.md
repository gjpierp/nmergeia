# PostgreSQL 中的高级优化

在高性能事务环境中，引擎调优至关重要。

## 解释分析和成本
使用“EXPLAIN ANALYZE”不仅可以显示执行计划，还可以显示实际的处理时间。允许您检测不需要的*顺序扫描*。

## GIN、GiST 和 B 树索引
- **B 树：** 精确搜索和范围的理想选择。
- **GIN：** 对于全文搜索或 JSONB 数组至关重要。

## 维护：同时重新索引
防止写锁，同时维护损坏或降级的索引（膨胀）。

````美人鱼
图LR
  A[查询 SQL] --> B{解释}
  B -->|顺序扫描| C[创建索引]
  B -->|索引扫描| D[优化]
  C --> E[同时重新索引]
````
