# NGAC 应用于菜单和动态视图

将 Sentinel-NGAC 集成到前端涉及在运行时解析权限图。

## 图形分辨率
当用户登录时，NGAC后端计算从其节点（用户）到菜单对象（对象）的所有有效路由。

## 成功案例：safi-core
在像“safi-core”这样的大型 ERP 系统中，菜单响应缓存在 Redis 中。如果权限发生变化，缓存就会失效。

````美人鱼
序列图
  前端->>+后端：请求/菜单（JWT）
  后端->>+Sentinel-NGAC：检查路径
  Sentinel-NGAC-->>-后端：允许的对象
  后端-->>-前端：菜单树
````
