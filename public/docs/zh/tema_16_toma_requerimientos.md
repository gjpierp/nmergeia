# 高级需求获取和 DDD

有效的需求捕获是成功产品的基石，从静态文档转向协作发现。

## 领域驱动设计（DDD）
通过*Ubiquitous Language*（通用语言）将业务的心智模型与代码统一起来的方法。
- **有界上下文：** 术语具有单一含义的显式边界。

## 事件风暴
可视化研讨会技术（使用便利贴）通过识别*域事件*、*命令*和*聚合*来对复杂的业务流程进行建模。

``美人鱼
图LR
  A[命令：创建订单] --> B[添加：订单]
  B --> C[事件：订单已创建]
  C --> D[政策：通知发货]
  D --> E[命令：发送邮件]
````

> [!NOTE]
> 白皮书的其余部分保留其原始语言，以保留代码和图表的语法。
