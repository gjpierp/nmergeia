# 多租户和多语言 SaaS 架构

## 数据隔离
1. **筒仓：** 每个客户端一个数据库（昂贵，安全）。
2. **池：** 同一个表中带有 `tenant_id` + RLS（经济）的所有行。
3. **桥：**同一数据库中每个客户端一个模式。

## 全球位置
在 React 中使用像“i18next”这样的库来处理异步动态字典。

````美人鱼
图解TD
  A[API 网关] --> B[租户 A 架构]
  A --> C[租户 B 架构]
  A --> D[租户 C 架构]
````
