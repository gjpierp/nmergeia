# NGAC 指南：高级

> [!重要]
> 在高级级别，我们开始组合多个图（称为“策略”或策略类），并添加动态属性，例如时间或位置（NGAC 中的 ABAC）。

## 条件评估

在高级 NGAC 中，图中的一条路径是不够的。我们可以将“条件”与关联联系起来。

### 时间和状态限制

````美人鱼
图解TD
    U[用户：收银员] -->|UA|收银员（收银员）
    
    收银员 -- 可以处理 --> OA1（收银机）
    
    收银员-.条件：仅工作时间.-> OA1
    
    O[方框 01] --> OA1
    O2[方框02] --> OA1
````

如果用户“Cashier”尝试在凌晨 3:00 访问“Cash 01”，NGAC 引擎会找到路径，但边缘条件失败。因此，访问被拒绝。

### 职责分离 (SoD)

NGAC 允许您通过声明 **Ban Constraints** 轻松实现 SoD。 
- 如果 Alice 批准购买请求，图表会动态生成一个节点，**拒绝** Alice 签署同一购买支票的权利。

> [!提示]
> 通过利用动态对象属性，您可以以精细的方式隔离信息，而无需创建数百万个角色（角色爆炸）。
