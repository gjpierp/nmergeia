# 安全なシークレット管理と DevSecOps

シークレットのハードコーディングは重大な脆弱性です。 Swarm AI は認証情報の公開を禁止します。

## HashiCorp 保管庫
ダイナミックストレージ。 Vault は一時的な資格情報 (1 時間で期限切れになるデータベース ユーザーなど) を生成できます。

## SAST/DAST 統合
- **SAST:** CI パイプラインでの静的分析。
- **DAST:** ステージング内のコンテナーを攻撃する動的テスト。

「人魚」
グラフLR
  A[コミット] --> B[SonarQube/SAST]
  B --> C{それは起こりますか?}
  C -->|いいえ| D[CI 拒否]
  C -->|はい| E[ステージングへのデプロイメント]
  E --> F[DAST オワスプ ZAP]
