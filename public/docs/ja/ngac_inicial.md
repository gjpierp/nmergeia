# 初期レベル

> [!NOTE]
> NGAC (Next Generation Access Control) は、RBAC (Role-Based Access Control) および ABAC (Attribute-Based Access Control) の制限を克服するために設計された NIST 標準化されたアクセス制御モデルです。

## NGAC とは何ですか?

従来のモデルとは異なり、NGAC は有向グラフを通じてポリシーを表現することでポリシー管理を一元化します。 NGAC では、すべて (ユーザー、オブジェクト、操作) がグラフ内のノードであり、ユーザーからオブジェクトまでの有効なパスを見つけることによってアクセスが決定されます。

### NGAC と従来のモデルの比較

「人魚」
グラフTD
    A[従来のモデル] --> B(RBAC: 役割 -> 権限)
    A --> C(ABAC: 複雑で遅いルール)
    
    D[NGAC] --> E(関係グラフ)
    D --> F(線形かつ高速な評価)
    
    B -.-> G[拡張と監査が困難]
    C -.-> G
    
    E -.-> H[スケーラビリティと自然監査]
    F -.-> H
「」

> [!ヒント]
> システムがポリシーを急速に変更する必要がある場合 (たとえば、請負業者にシフト中のみアクセスを許可するなど)、NGAC はグラフのエッジを追加または削除するだけでこれを自然に処理します。

## 主な利点
1. **柔軟性:** 単一モデルで RBAC、ABAC、MAC、および DAC をエミュレートできます。
2. **監査:** 「このファイルにアクセスできるのは誰ですか?」という質問に答えます。は単純なグラフ走査クエリです。
3. **パフォーマンス:** 最新のグラフ データベースはミリ秒単位でアクセス許可を解決します。
