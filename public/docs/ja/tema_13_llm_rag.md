# LLM と企業 RAG の統合

## 内部データのプライバシー
企業はパブリック OpenAI/Anthropic API に PII を送信できません。

## RAG (検索拡張生成) アーキテクチャ
1. Vector DB の内部文書のインデックス作成 (Chroma、Pinecone)。
2. セマンティックコンテキストの回復。
3. LLM プロンプト (ローカルまたはプライベート) での注入。

「人魚」
グラフTD
  A[ユーザープロンプト] --> B[ベクターDB検索]
  B --> C[コンテキストの取得]
  C --> D[LLM 生成]
  D --> E[安全な答え]
「」
