# 高度なソフトウェア アーキテクチャ

システムの構造設計は、その拡張性、保守性、回復力を決定します。

## 六角形アーキテクチャ (ポートとアダプター)
ドメインのコアを外部の依存関係 (データベース、UI、API) から分離します。ドメインはインフラストラクチャを認識しません。
- **ポート:** ドメインによって定義されたインターフェイス。
- **アダプター:** ポートに接続する技術実装。

## イベント指向アーキテクチャ (EDA)
コンポーネントは、非同期イベントの発行と消費を通じて通信します (コレオグラフィーとオーケストレーション)。
- 高負荷および弱く結合されたシステムに最適です。
