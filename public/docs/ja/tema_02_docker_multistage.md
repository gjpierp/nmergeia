# マルチステージの Docker およびコンテナ戦略

Docker イメージの攻撃対象領域と重量を (50MB 未満に) 削減することは、DevSecOps の重要な目標です。

## マルチステージビルド
これにより、重いイメージ (例: `node:18-alpine`) でコードをコンパイルし、結果のバイナリまたは静的イメージのみをディストロレスまたはウルトラライト イメージ (例: `nginx:alpine`) に移動することができます。

## ローカル オーケストレーション用の Docker Compose
「docker-compose.yml」ファイルを使用すると、分離された仮想ネットワークを簡単にセットアップできます。

「人魚」
グラフTD
  A[ステージ 1: ビルド] -->|バイナリをコピー| B[ステージ 2: ディストロレス]
  B --> C[画像 < 50MB]
  C --> D[安全な展開]
「」
