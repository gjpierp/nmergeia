# メニューと動的ビューに適用される NGAC

Sentinel-NGAC をフロントエンドに統合するには、実行時に権限グラフを解決する必要があります。

## グラフの解像度
ユーザーがログインすると、NGAC バックエンドはノード (ユーザー) からメニュー オブジェクト (オブジェクト) までのすべての有効なルートを計算します。

## 成功事例: safi-core
「safi-core」のような大規模な ERP システムでは、メニューの応答は Redis にキャッシュされます。権限が変更された場合、キャッシュは無効になります。

「人魚」
シーケンス図
  フロントエンド->>+バックエンド: リクエスト/メニュー (JWT)
  バックエンド->>+Sentinel-NGAC: パスの確認
  Sentinel-NGAC-->>-バックエンド: 許可されたオブジェクト
  バックエンド-->>-フロントエンド: メニュー ツリー
「」

> [!NOTE]
> コードと図の構文を維持するために、ホワイト ペーパーの残りの部分は元の言語のままになっています。
