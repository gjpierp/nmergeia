# マルチテナントおよび多言語の SaaS アーキテクチャ

## データの分離
1. **サイロ:** クライアントごとに 1 つのデータベース (高価で安全)。
2. **プール:** `tenant_id` + RLS (エコノミック) を持つ同じテーブル内のすべての行。
3. **ブリッジ:** 同じデータベース内のクライアントごとに 1 つのスキーマ。

## グローバルな場所
React の「i18next」のようなライブラリを使用して、非同期動的辞書を処理します。

「人魚」
グラフTD
  A[API ゲートウェイ] --> B[テナント A スキーマ]
  A --> C[テナント B スキーマ]
  A --> D[テナント C スキーマ]
「」

> [!NOTE]
> コードと図の構文を維持するために、ホワイト ペーパーの残りの部分は元の言語のままになっています。
