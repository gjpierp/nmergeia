# DB間の移行と相互運用性

レガシーまたはオンプレミスのデータベースを終了するための戦略 (Oracle から Postgres へなど)。

## 移行ツール
CDC (変更データ キャプチャ) レプリケーションに *AWS SCT (スキーマ変換ツール)* および *DMS (データ移行サービス)* を使用します。

## ストラングラー フィグ戦略
テーブルからテーブルに移行します。アプリケーションは整合性が確認されるまで二重書き込みを行います。
