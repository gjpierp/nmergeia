# 高度な要件の取得と DDD

効果的な要件の把握は製品の成功の基礎であり、静的な文書から共同発見に向けて移行しています。

## ドメイン駆動設計 (DDD)
ビジネスのメンタルモデルとコードを*ユビキタスランゲージ*(ユビキタス言語)で統一するアプローチ。
- **境界付きコンテキスト:** 用語が単一の意味を持つ明示的な境界。

## イベントストーミング
*ドメイン イベント*、*コマンド*、および *集計* を識別することで、複雑なビジネス フローをモデル化するビジュアル ワークショップ手法 (ポストイットを使用)。

「人魚」
グラフLR
  A[コマンド: オーダーの作成] --> B[追加: オーダー]
  B --> C[イベント: 注文が作成されました]
  C --> D[ポリシー: 出荷通知]
  D --> E[コマンド: メール送信]
「」

> [!NOTE]
> コードと図の構文を維持するために、ホワイト ペーパーの残りの部分は元の言語のままになっています。
