# 高度な Git ワークフロー

大規模なコラボレーションには、効率的な分岐戦略が必要です。

## トランクベースの開発と GitFlow の比較
- **トランクベース:** 「メイン」への直接の継続的統合。 *機能フラグ* と厳密な TDD が必要です。衝突を減らします。
- **GitFlow:** 厳密にバージョン管理されたリリース (「開発」、「リリース」、「メイン」) に最適です。
