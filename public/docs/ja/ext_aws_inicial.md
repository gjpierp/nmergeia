# AWS Serverless 初期：クラウドコンピューティングとサーバーレスアーキテクチャ

クラウドへようこそ。何十年もの間、アプリケーションをホストすることは、物理サーバー（ベアメタル）をレンタルすることを意味していました。その後、仮想マシン（EC2）とコンテナ（Docker）に移行しました。今日、進化の頂点にあるのが **Serverless（サーバーレス）** です。

## 1. 「サーバーレス」とはどういう意味ですか？

サーバーレス (Serverless) は、サーバーが魔法のように消えたことを意味するわけではありません。**サーバーの管理、スケーラビリティ、およびメンテナンスが、あなたにとって完全に「見えなくなる」**ことを意味します。

```mermaid
graph LR
    Usuario[ユーザー] -->|HTTP リクエスト| API[API Gateway]
    API -->|トリガー| Lambda[AWS Lambda (コード)]
    Lambda -->|クエリ| DB[(DynamoDB)]
    
    subgraph sub_1 ["OSの管理、パッチ適用、RAMの管理は行いません"]
        API
        Lambda
        DB
    end
```

### 根本的な利点
* **実際の使用に対する従量課金：** 週末にアプリケーションのユーザーが0人の場合、支払う金額は正確に $0.00 です（24時間365日課金されるVPSとは異なります）。
* **無限かつ瞬時のスケーリング：** 1秒でユーザーが10人から10,000人に増えた場合、AWSはあなたが何もせずに自動的にあなたのコードを何千回も複製します。
* **ゼロメンテナンス：** Linuxのバージョンを更新したり、カーネルのセキュリティパッチをインストールしたりする必要は二度とありません。

## 2. AWS Serverless の柱

AWSのサーバーレスエコシステムは、3つの基本的なレゴブロックで構築されています。

| サービス | 機能 | 従来の類似技術 |
| :--- | :--- | :--- |
| **API Gateway** | 門番。HTTP リクエストを受信し、Auth を検証してルーティングします。 | Nginx / Apache / Express Router |
| **AWS Lambda** | 脳。コード (Node.js, Python, Go) をミリ秒単位で実行します。 | あなたのコントローラー / ビジネスロジック |
| **DynamoDB** | 記憶。レイテンシ 1 ミリ秒の NoSQL データベース。 | MongoDB / PostgreSQL |

## 3. コードにおけるパラダイムシフト

従来のNode.jsサーバーでは、ポートをリスンして（`app.listen(3000)`）サーバーを起動します。サーバーレスでは、**あなたのコードはイベントによって呼び起こされるまで「眠って」います**。

```javascript
// これが AWS Lambda の外観です。サーバーはなく、純粋な関数のみです。
export const handler = async (event) => {
  // 'event' には API Gateway が受信したものすべて (Headers, Body) が含まれます
  console.log("受信したイベント:", event.body);
  
  return {
    statusCode: 200,
    body: JSON.stringify({ mensaje: "サーバーレスクラウドからのこんにちは！" }),
  };
};
```
