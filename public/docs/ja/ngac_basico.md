# 基本レベル

> [!重要]
> NGAC をマスターするには、まずその基本的な構成要素を理解する必要があります。各要素は認可グラフ内のノードです。

## 中心要素 (基本コア)

NGAC は、次の 5 つの主要なタイプの要素に基づいています。

1. **U (ユーザー):** アクセスを要求するエンティティ。
2. **O (オブジェクト):** 保護されているリソース (ファイル、データベース レコード、URL)。
3. **UA (ユーザー属性):** ユーザーのグループ (役割、部門、役職など)。
4. **OA (オブジェクト属性):** オブジェクトのグループ化 (フォルダー、機密ラベルなど)。
5. **Op (操作):** 許可されるアクション (読み取り、書き込み、削除)。

### 関係グラフ

NGAC におけるアクセス制御は、ユーザー (U) からオブジェクト (O) までのパスを追跡することによって決定されます。

「人魚」
グラフTD
    U1[ユーザー: アリス] -->|割り当て先| UA1(ユーザー属性:IT部門)
    UA1 -->|"読み取り/書き込み可能"| OA1(オブジェクト属性: 運用サーバー)
    O1[オブジェクト: アプリサーバー 1] -->|所属| OA1
    
    U2[ユーザー: ボブ] -->|割り当て先| UA2(ユーザー属性:マーケティング)
    UA2 -->|読み取り可能| OA2(オブジェクト属性: 公開レポート)
    O2[オブジェクト: レポート Q1] -->|所属| OA2
「」

> [!NOTE]
> この図では、「Alice -> IT 部門 -> (読み取り/書き込み) -> 運用サーバー <- App Server 1」という有効なパスがあるため、Alice は「App Server 1」の権限を継承します。

＃＃ 協会

> [!NOTE]
> コードと図の構文を維持するために、ホワイト ペーパーの残りの部分は元の言語のままになっています。

ones
Las asociaciones son aristas especiales que conectan un `UA` con un `OA` y contienen las Operaciones (Op). Las aristas regulares de pertenencia no contienen operaciones.
