# コードとしてのインフラストラクチャと不変性

Infrastructure as Code (IaC) により、環境の再現性が保証されます。

## Terraform と分散状態
Terraform は「terraform.tfstate」ファイルを使用してクラウド リソースをマッピングします。リモートに保存する必要があります (例: ロックの場合は S3 + DynamoDB)。

## Blue-Green および Canary デプロイメント
- **青-緑:** 2 つの同一の環境。ダウンタイムゼロ。
- **カナリア:** ユーザーの 5% に段階的に展開し、エラーがなければ段階的に拡張します。
