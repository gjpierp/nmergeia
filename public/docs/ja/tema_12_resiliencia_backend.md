# バックエンドの復元力とフォールト トレランス

最新のシステムは、ネットワークが信頼できるものであることを前提としていません。

##サーキットブレーカー
外部マイクロサービスが継続的に失敗すると、実行スレッドをフリーズするのではなく、高速エラーを返すことによってループが「オープン」します。

## レート制限とスロットリング
DDOS や悪用からの保護。 Redis を使用した *Token Bucket* アルゴリズム。

「人魚」
グラフLR
  A[クライアント] --> B[API ゲートウェイ]
  B -->|遅い通話| C{サーキットブレーカー}
  C -->|開く| D[フォールバック応答]
  C -->|クローズ| E[ロイヤルサービス]
「」

> [!NOTE]
> コードと図の構文を維持するために、ホワイト ペーパーの残りの部分は元の言語のままになっています。
