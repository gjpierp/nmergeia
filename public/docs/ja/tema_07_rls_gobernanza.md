# データ層セキュリティ (RLS)

行レベル セキュリティ (RLS) は、アプリのテナント フィルタリング ロジックをデータベースに直接転送します。

## Postgres における RLS の利点
テナント ID を指定せずに「SELECT * FROM invoices」を実行する悪意のあるクエリは、0 行を返します。

## ガバナンスとポリシー
RLS ポリシーは、「ALTER TABLE invoices ENABLE ROW LEVEL SECURITY;」を使用して有効にします。
