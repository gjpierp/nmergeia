# Oracle DB: Nivel Básico - Estructuras y DDL

Una vez que tenemos nuestro entorno de Oracle funcionando, es momento de comprender la arquitectura lógica y física básica de Oracle, y cómo crear y manipular los objetos que almacenarán nuestra información.

## 1. Arquitectura Lógica: Tablespaces y Usuarios

A diferencia de otros motores donde simplemente creas una "Base de Datos", en Oracle los datos se organizan lógicamente en **Tablespaces** y los objetos pertenecen a un **Esquema** (que generalmente es sinónimo de un Usuario).

### Creación de un Tablespace
Un tablespace es un área lógica que apunta a uno o varios archivos físicos (`.dbf`).

```sql
CREATE TABLESPACE inventario_tbs
DATAFILE 'inventario01.dbf' SIZE 100M AUTOEXTEND ON NEXT 50M MAXSIZE 1G;
```

### Creación de un Usuario/Esquema
Para trabajar de forma segura, creamos un usuario y le asignamos el tablespace que acabamos de crear.

```sql
-- En Oracle 12c+ (arquitectura multitenant), los usuarios locales suelen llevar el prefijo c## a menos que cambies de PDB.
-- Para desarrollo rápido en el contenedor:
ALTER SESSION SET "_ORACLE_SCRIPT"=true; 

CREATE USER app_inventario IDENTIFIED BY "<tu_contraseña_segura>"
DEFAULT TABLESPACE inventario_tbs
QUOTA UNLIMITED ON inventario_tbs;

-- Dar permisos de conexión y creación de objetos
GRANT CONNECT, RESOURCE TO app_inventario;
```

## 2. Creación de Tablas (DDL)

Una vez conectados con nuestro usuario `app_inventario`, podemos empezar a crear tablas. Oracle soporta tipos de datos estándar y propios, como `VARCHAR2` y `NUMBER`.

```sql
CREATE TABLE productos (
    producto_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nombre VARCHAR2(150) NOT NULL,
    precio NUMBER(10,2) DEFAULT 0,
    fecha_creacion DATE DEFAULT SYSDATE
);

CREATE TABLE categorias (
    categoria_id NUMBER PRIMARY KEY,
    nombre VARCHAR2(100) NOT NULL
);
```

### Tipos de Datos Más Comunes
- `VARCHAR2(n)`: Cadenas de longitud variable (hasta 4000 bytes o 32k). Siempre prefiere este sobre `VARCHAR`.
- `NUMBER(p, s)`: Números. `p` es la precisión (total de dígitos) y `s` es la escala (dígitos decimales).
- `DATE`: Almacena fecha y hora (hasta los segundos).

## 3. Modificación de Tablas

Si necesitas ajustar la estructura después de la creación:

```sql
-- Añadir una nueva columna
ALTER TABLE productos ADD (descripcion VARCHAR2(500));

-- Modificar el tipo de una columna
ALTER TABLE productos MODIFY (nombre VARCHAR2(200));

-- Eliminar una tabla
DROP TABLE categorias CASCADE CONSTRAINTS;
```

Comprender la relación entre Usuarios y Tablespaces es vital en Oracle. En el próximo nivel, entraremos de lleno en la manipulación de datos (DML) y transacciones.
