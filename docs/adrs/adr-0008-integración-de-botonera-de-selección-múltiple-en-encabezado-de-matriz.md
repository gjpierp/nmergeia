# ADR 0008: Integración de Botonera de Selección Múltiple en Encabezado de Matriz
 
* **Fecha**: 2026-08-07
* **Estado**: Aceptado
 
## Contexto y Planteamiento del Problema
El usuario solicitó eliminar la etiqueta '- Estructura de Archivos' y mover la botonera de acciones por lote al encabezado superior junto al control 'Seleccionar todo' utilizando botones Icon-Only.
 
## Decisión
Se removió la barra flotante inferior y se integraron las acciones en lote (Copiar/Borrar en Origen y Destino) dentro de matrix-header junto al checkbox de Seleccionar todo con el estándar Icon-Only.
 
## Consecuencias
Mayor espacio útil vertical y experiencia de usuario unificada.
